# [Thực hành] Tạo trang web cá nhân với CSS

Bài thực hành xây dựng trang web giới thiệu cá nhân sử dụng HTML5 và CSS3 theo yêu cầu bài học.

## 📌 Mục tiêu đạt được
- **Nhúng CSS vào HTML**: Sử dụng liên kết ngoài qua thẻ `<link rel="stylesheet" href="style.css">`.
- **Bộ chọn CSS (Selectors)**: 
  - Bộ chọn thẻ (Type Selectors): `body`, `header`, `section`, `ul`, `li`, `footer`, `table`, `th`, `td`.
  - Bộ chọn lớp (Class Selectors): `.profile`, `.avatar`, `.hobbies`, `.goals`.
- **Đường viền (Border)**: Định dạng viền tròn cho avatar (`border-radius: 50%`, `border: 3px solid #4CAF50`) và viền bảng gọn gàng (`border-collapse: collapse`).
- **Màu nền & Ảnh nền**:
  - `background-color`: Màu xanh chủ đạo `#4CAF50`, màu nền dịu mắt `#f5f5f5`, nền footer `#ddd`.
  - `background-image`: Phối hợp gradient hiện đại cho header và họa tiết nền tinh tế cho body.
- **Màu sắc & Phông chữ**: Bố cục chữ dễ đọc, tương phản tốt, font chữ `Arial, sans-serif`.

## 📁 Cấu trúc thư mục
```text
personal-website-css/
├── index.html       # Mã nguồn cấu trúc giao diện HTML5
├── style.css        # Mã nguồn định dạng kiểu dáng CSS3
├── avatar.jpg       # Ảnh đại diện cá nhân
└── README.md        # Tài liệu hướng dẫn & giới thiệu bài làm
```
